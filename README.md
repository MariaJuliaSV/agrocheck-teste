# AgroCheck
Sistema de identificação de doenças em folhas de milho e batata utilizando inteligência artificial (MobileNetV2 + transfer learning).

Classes: Milho (Ferrugem comum, Mancha cinzenta, Helmintosporiose, Saudável) e Batata (Pinta-preta, Requeima, Saudável).
Acurácia no conjunto de teste: 96,6%.
